

# AI社内マニュアル検索システム

社内マニュアル(PDF / Word / テキスト)を登録し、自然な文章で質問すると、
マニュアルの内容だけに基づいて回答と根拠(出典)を返すシステムです(RAG方式)。



## 使用技術
Python 3.13 / FastAPI / OpenAI API / ChromaDB / SQLite / PyMuPDF / python-docx

## セットアップ(Windows PowerShell)

```powershell
# 1. 仮想環境を作る(最初の1回だけ)
python -m venv .venv

# 2. 仮想環境を有効にする(PowerShellを開くたびに)
.\.venv\Scripts\Activate.ps1

# 3. ライブラリを入れる
pip install -r requirements.txt

# 4. 設定ファイルを作る
copy .env.example .env
#    .env を開き、OPENAI_API_KEY に自分のキーを書く(ステップ5から必要)
```

## 最初の管理者を作る(初回だけ)

```powershell
python -m app.create_admin
```

ユーザー名とパスワード(8文字以上)を入力します。以降のユーザーは、管理者でログインして「ユーザー管理」から追加します。

## 起動

```powershell
uvicorn app.main:app --reload --port 8001
```

ブラウザで http://127.0.0.1:8001/health を開き、`"status":"ok"` が出れば成功です。
画面は http://127.0.0.1:8001/ から使えます。

## テスト

```powershell
pytest
```

## 注意
- `.env` と `data/` は Git に含めません(秘密情報・個人データのため)。
- HTTPS で公開する場合は `.env` の `COOKIE_SECURE=true` を設定してください。

## 使い方
1. `.env` に `OPENAI_API_KEY` を設定して起動します。
2. http://127.0.0.1:8001/ を開き、ログインします。
3. 管理者は「マニュアル」でPDF / Word / テキストを登録します(一般ユーザーは閲覧のみ。マニュアルは全員共通です)。
4. 「質問する」で質問すると、登録マニュアルだけを根拠にした回答と出典が表示されます。回答文の `[1]` などの番号は、出典の番号に対応します(回答に使われた資料だけが出典に出ます)。「検索対象」で特定のマニュアルだけに絞ることもできます。
5. 「質問履歴」で自分の過去の質問・回答・出典を確認・削除できます(他の人の履歴は見えません)。キーワード(質問・回答の部分一致)と評価で絞り込めます。「CSVでダウンロード」で、絞り込み中の履歴をExcelで開けるCSVとして保存できます。

| 権限 | できること |
|---|---|
| 管理者 | 質問・履歴、マニュアルの登録/更新/削除、ユーザーの追加/削除/パスワードリセット、回答の評価の集計、操作ログの閲覧 |
| 一般 | 質問・自分の履歴、マニュアルの閲覧 |

パスワードは、ログイン後の「パスワード変更」タブから本人が変更できます(現在のパスワードが必要。他の端末のログインは無効になります)。

- **会話の続き**: 回答のあとに「それはいつまで?」のように続けて質問できます(直前の最大3件のやり取りを踏まえて、指示語を補います。検索にも直前の質問を使います)。「新しい会話を始める」で区切れます。回答の根拠は常に今回見つかった資料だけです。履歴に保存されるのは、これまで通り1回ごとの質問と回答です。
- **回答のストリーミング表示**: 回答が生成されるそばから画面に表示されます(完了時に出典・評価ボタンが出ます)。途中で失敗した場合はエラーを表示し、履歴には保存されません。
- **回答の評価**: 回答の下の「役に立った / 役に立たなかった」ボタンで評価できます(もう一度押すと取り消し)。管理者は「回答の評価」タブで、満足率・マニュアル別の評価(「役に立たなかった」の割合が高い順)・「役に立たなかった」回答の一覧を確認でき、マニュアルの不足や古い内容の見直しに使えます。
- **利用状況**: 管理者の「回答の評価」タブの先頭に、質問の総数・直近7日/30日の質問数・利用者数・回答できなかった数、直近14日の日別の質問数、質問が多いユーザー(直近30日・上位5人)を表示します。
- **回答できなかった質問**: 管理者の「回答の評価」タブの下部に、資料が見つからず回答できなかった質問(全ユーザー分・新しい順)を表示します。マニュアルの不足を見つける手がかりになります。
- **マニュアルの分類**: 管理者は登録時に分類(例: 経理・人事。30文字以内、任意)を付けられ、一覧の「分類」ボタンでいつでも変更できます(空欄で未分類)。「質問する」の「分類」で選ぶと、その分類のマニュアルだけを検索します(「検索対象」のマニュアルと組み合わせも可能)。マニュアルを差し替えても分類は残ります。
- **マニュアル一覧の絞り込み**: 「マニュアル」タブの検索欄に入力すると、ファイル名・分類の部分一致で一覧を絞り込みます(未分類は「未分類」で探せます)。
- **元ファイルのダウンロード**: 「マニュアル」一覧の「ダウンロード」と、回答の出典の「元のファイルをダウンロード」から、登録されている元のPDF / Word / テキストを取得できます(ログインしていれば誰でも可)。
- **マニュアルの更新**: 管理者は登録済みマニュアルを別のファイルに差し替えられます。新しいファイルの解析に成功してから入れ替えるので、失敗しても元のマニュアルは残ります。
- **操作ログ**: 管理者は「操作ログ」タブで、ログイン履歴やユーザー・マニュアルの操作を種類で絞り込んで確認でき、「CSVでダウンロード」で絞り込み中のログをCSVに保存できます(最大5000件)。

## API
自動生成のAPI仕様は http://127.0.0.1:8001/docs で確認できます。

| メソッド | パス | 内容 |
|---|---|---|
| POST | /api/auth/login | ログイン |
| POST | /api/auth/logout | ログアウト |
| GET | /api/auth/me | ログイン中のユーザー |
| PUT | /api/auth/password | 自分のパスワード変更 |
| GET/POST | /api/users | ユーザー一覧/追加(管理者) |
| PUT | /api/users/{id}/password | パスワード変更(管理者) |
| DELETE | /api/users/{id} | ユーザー削除(管理者) |
| POST | /api/manuals | マニュアル登録(管理者・分類は任意) |
| PUT | /api/manuals/{id}/category | マニュアルの分類変更(管理者) |
| GET | /api/manuals/{id}/file | 元ファイルのダウンロード |
| PUT | /api/manuals/{id} | マニュアル更新(ファイル差し替え・管理者) |
| GET | /api/manuals | マニュアル一覧 |
| DELETE | /api/manuals/{id} | マニュアル削除(管理者) |
| POST | /api/ask | 質問(回答+出典。manual_id / category で絞り込み可・previous_ids で会話の続き) |
| POST | /api/ask/stream | 質問(回答を少しずつ送るSSE版。画面はこちらを使用) |
| GET | /api/history | 質問履歴の一覧(q: キーワード / rating: good・bad・none で絞り込み可) |
| GET | /api/history/export.csv | 質問履歴のCSV出力(q / rating の絞り込み可) |
| GET | /api/history/{id} | 質問履歴の詳細 |
| DELETE | /api/history/{id} | 質問履歴の削除 |
| PUT | /api/history/{id}/rating | 回答の評価(本人のみ・取り消し可) |
| GET | /api/feedback/summary | 評価の集計(管理者) |
| GET | /api/feedback/usage | 利用状況(質問数・日別の推移・質問が多いユーザー。管理者) |
| GET | /api/feedback/unanswered | 回答できなかった質問の一覧(管理者) |
| GET | /api/audit | 操作ログ一覧(管理者・種類で絞り込み) |
| GET | /api/audit/export.csv | 操作ログのCSV出力(管理者・種類で絞り込み可) |
